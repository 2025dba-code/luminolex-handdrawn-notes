# Content Decomposition & Visual Translation Rules

## 1. Decompose by meaning, not paragraphs

A paragraph may contain zero, one, or several visual nodes.
A visual node exists when the source contains a concept that deserves independent understanding or recall.

## 2. What deserves its own visual node

Usually create a separate image for:
- central thesis
- key distinction
- framework element
- important risk
- common mistake
- disqualifying behavior
- major example
- professional boundary
- practical technique
- level progression
- assessment criterion
- memorable question
- cause-effect relationship
- critical exception
- synthesis

## 4. Scene diversity rule

No more than 2 consecutive images should use the same generic setup: “two people sit across a table and talk.”

When a third similar image would occur, translate the concept into:
- spatial metaphor
- decision path
- layered model
- time axis
- object-based illustration
- workplace scenario
- team scene
- journey / map
- diagnostic view

## 5. Long chapter rule

For chapters longer than ~5,000 Chinese characters, first create a section map and estimate required visuals per section based on conceptual density.

Do not produce 20 images by habit.

Example:
- foundational definition: 3–5
- assessment criteria: 5–10
- each major criterion: 4–8
- examples / failure modes: 1 per meaningful case
- level progression: 2–4
- learning summary: 1–3

## 6. Professional-competency rule

For ICF / certification / professional standards content, visualize:
1. Definition
2. Intent behind the competency
3. Professional boundary
4. Assessment standard
5. Positive indicators
6. Failure / disqualifying indicators
7. Common mistake
8. Case example
9. How to avoid the mistake
10. Level progression
11. Learning points

Do not reduce the material to motivational slogans.

## 7. Cases

A case deserves its own image when:
- it reveals a subtle error
- the wrong behavior looks superficially reasonable
- the case is used to define an assessment boundary
- the case produces a memorable learning point

Show the decision or mechanism, not every sentence of the case.

## 8. Completeness audit

After drafting the image list, compare it to the source section-by-section.

Mark each major source idea as:
- Covered
- Combined intentionally
- Not visualized (with reason)

If a core idea is “not visualized,” add an image.
Do not silently omit content just to keep the list short.
