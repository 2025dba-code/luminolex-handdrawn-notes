# Prompt Template

Use this template as a flexible structure, not a rigid form.

## 图XX｜[short visual title]

[Scene]
Describe the physical or conceptual environment.

[Characters]
Specify credible Chinese workplace professionals aged 25–40 unless the source requires otherwise.

[Action]
Describe what each person is doing. Body language should communicate the concept.

[Key objects]
Include only objects that carry meaning.

[Visual metaphor]
Explain how the abstract concept becomes visible.

[Composition]
State relative position, hierarchy, direction, distance, or visual flow.

[Highlight]
Use champagne gold only for the critical path / relationship / target / boundary / insight.

[Core Chinese text]
Use one short phrase or 1–3 short labels only.

[Meaning]
State what the viewer should understand from the image.

[Style]
Square 1:1, premium hand-drawn editorial business illustration, warm off-white paper,
deep navy + champagne gold + warm gray, refined linework, light watercolor / marker texture,
Chinese workplace professionals aged 25–40, generous negative space, mature and restrained,
no anime, no childish style, no logo, no large text block.

# Prompt quality rules

A good prompt:
- describes a picture, not only an idea
- makes the relationship between elements visible
- uses one main metaphor
- has a clear focal point
- is immediately drawable

A weak prompt:
- repeats source paragraphs
- uses vague words like “show leadership”
- contains too many abstract nouns
- asks for 10 separate concepts in one frame
- relies on long text inside the image
