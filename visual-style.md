# Luminolex Visual Style v1.0

## 1. Default format

Default illustration format:
- Square 1:1
- Premium editorial business illustration
- Hand-drawn management-book visual language

If the user explicitly asks for video page / vertical video assets:
- use 9:16
- preserve the same visual identity

Do not change aspect ratio merely because the source is long.

## 2. Characters

Default:
- Chinese workplace professionals
- Age: 25–40
- Mature
- Professional
- Restrained
- Natural body proportions
- Realistic workplace posture

Avoid:
- childlike faces
- teenage styling
- anime
- chibi
- exaggerated cartoon expressions
- overly glamorous fashion illustration

Characters should look like credible managers, coaches, professionals, HR practitioners, engineers, or knowledge workers depending on the source.

## 3. Palette

Background:
- warm off-white premium paper
- subtle natural paper texture

Primary:
- deep navy blue

Secondary:
- champagne gold
- warm gray
- low-saturation blue-gray

Champagne gold is reserved for:
- correct path
- important relationship
- key boundary
- key turning point
- insight
- target
- shared agreement
- customer-generated solution
- important action

Do NOT use gold as general decoration.

## 4. Rendering

Use:
- refined hand-drawn linework
- light watercolor wash
- subtle marker texture
- editorial illustration
- restrained shading
- visual breathing space

The image should evoke:
- Harvard Business Review editorial illustration
- high-end business book illustration
- international management consulting report
- professional coaching textbook

Do not imitate any single living artist.

## 5. Composition

Default:
- one image = one core idea
- high visual clarity
- generous negative space
- strong visual hierarchy
- 1–3 primary figures
- only add more figures when the concept requires a team/group

Avoid:
- crowded scenes
- large text blocks
- dense data tables
- excessive props
- visual noise

## 6. Typography inside illustrations

Chinese mode:
- allow only a few short Chinese keywords
- short title / concept label is acceptable
- no paragraph text
- no small unreadable text
- no English gibberish

International mode:
- use English keywords only when needed
- prefer language-light imagery

Never include:
- real corporate logos
- trademarked interfaces
- fake citations
- long source quotes

## 7. Visual motifs

Preferred visual motifs:
- path / road
- bridge
- compass
- map
- mirror
- spotlight
- boundary line
- protective circle
- ladder / steps
- forked road
- roots
- iceberg
- time axis
- signal path
- loop
- door
- transparent wall
- scale
- light beam
- orbit
- concentric circles
- shared table
- co-created map

Use metaphors because they clarify the concept, not as decoration.

## 8. Chinese / international mode

Default = Chinese visual mode.

Only switch to international mode if user explicitly asks for:
- 国际版
- 英文版
- English
- international

Do not infer international mode merely because the source is English.
